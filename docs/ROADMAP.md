# Leman Mail — Plan produit 3 ans

## Année 1 — Fondations & lancement (T1–T4)

**T1 — MVP sécurisé (ce dépôt)**
- Multi-comptes IMAP/SMTP + Gmail + Microsoft 365 (OAuth2 PKCE)
- Boîte unifiée offline-first, moteur anti-phishing, protection trackers
- Newsletter Cleaner, Smart Cleanup, Inbox Health Score, Security Center
- Gamification v1, dark/light, onboarding

**T2 — Bêta publique**
- TestFlight / Play closed testing (500 → 5 000 testeurs)
- Push notifications (FCM/APNs), IMAP IDLE arrière-plan
- Localisation EN + DE + IT (marché suisse d'abord)
- Passage revue sécurité Google (CASA) pour scopes Gmail

**T3 — Lancement commercial v1.0**
- Stores publics, site lemanmail.com, pricing : Free / Premium 4,99 €/mois
- Backend SaaS minimal (comptes Leman, licences, RevenueCat)
- Premium v1 : résumés IA + recherche naturelle (via passerelle backend)

**T4 — Consolidation**
- Extraction de tâches / rendez-vous → calendrier
- Widgets iOS/Android (Health Score, emails prioritaires)
- Objectif fin A1 : 50 k installs, 2 % conversion premium

## Année 2 — Intelligence & B2B

- Assistant IA de boîte de réception (tri, priorisation, urgences)
- Intégration Microsoft 365 avancée : Teams, OneDrive, création d'événements
- Threat intelligence Leman Cyber Security : flux de domaines malveillants
  mutualisé (opt-in, hashé, k-anonymat)
- Offre **Leman Mail Business** : MDM, politiques d'entreprise, console
  d'administration web, rapports de sécurité d'équipe
- SOC 2 Type I ; objectif : 250 k installs, 15 k abonnés

## Année 3 — Plateforme

- Client desktop (Flutter macOS/Windows) et web companion
- API publique + automatisations (règles no-code, webhooks)
- Chiffrement bout-en-bout inter-utilisateurs Leman (OpenPGP)
- Marketplace d'intégrations (CRM, ticketing)
- SOC 2 Type II, ISO 27001 ; objectif : 1 M installs, 60 k abonnés,
  ARR ≈ 3 M€

## KPIs suivis dès la v1

Activation (compte ajouté < 5 min), rétention J30, emails nettoyés/utilisateur,
menaces détectées, NPS, conversion free→premium, churn mensuel.
